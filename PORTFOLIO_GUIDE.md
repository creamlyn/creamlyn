# Personal Portfolio Website

This repository is named `creamlyn/creamlyn`, so **README.md** is also displayed on the GitHub profile. The separate portfolio website is built with HTML, CSS, and JavaScript.

## Files
- `index.html`: site sections and content
- `style.css`: dark visual theme and responsive design
- `script.js`: accessible mobile navigation and footer year
- `README.md`: GitHub profile introduction

## Running the site
Open `index.html` in any modern browser. No installation is required.

## Publishing to GitHub Pages
1. Visit repository **Settings > Pages**.
2. For Build and deployment choose **Deploy from a branch**.
3. Select **main** and **/(root)**. Save.
4. Once GitHub Pages deploys, visit https://creamlyn.github.io/creamlyn/.

This site is not public at that URL until GitHub Pages is enabled and the deployment is completed.

## Editing
Replace introductory text and project descriptions in `index.html`. Add working links once project demos and repositories are available. Change the theme colors in `style.css`. Your photo is currently loaded from your public GitHub profile avatar.

## Project Nexus connection
GitHub stores code and makes commits traceable. Use a **branch** to make a change without affecting the stable version, then open a **pull request** to review and merge it. This repository doubles as a developer portfolio and a practical example for discussing version control and project lifecycle management.
